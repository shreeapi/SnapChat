# 👻 Snap Profile API

A lightweight **Node.js + Express API** for retrieving publicly available Snapchat profile information through the Snap Profile Viewer service.

> 👨‍💻 Developer: **@shreeapi**

> GitHub: **@shreeapi**

---

## ✨ Features

- 👻 Snapchat username lookup
- 🔎 Public profile lookup
- ⚡ JSON API
- 🔄 Fresh nonce on every request
- @username support
- 🚀 Node.js + Express
- 📦 Axios HTTP client
- 🌐 REST API
- 🖥️ VPS support
- ☁️ Render support
- 🚂 Railway support
- 💻 Windows RDP / Server support
- 🔥 PM2 support
- 🌐 Cloudflare Tunnel support
- 💾 No database required
- 🔑 No API key required by this wrapper

---

# 📌 Uses

This API can be used as a backend component for applications that need to work with **public Snapchat profile information**.
